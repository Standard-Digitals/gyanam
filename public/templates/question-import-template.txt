GYANM Academy - Quiz / Mock Test Question Import Template

INSTRUCTIONS (delete this instructions block before uploading, or leave it - it will be ignored):

1. Type each question starting with "Q1.", "Q2.", "Q3." and so on, on its own line.
   Do NOT use Word's automatic numbered list feature - just type "Q1." as plain text.
2. For a Multiple Choice question, list 2 to 6 options below it as A) B) C) D) ...
3. For a Fill in the Blank question, add the tag [FILL] right after the question
   number (e.g. "Q2. [FILL] ...") and skip the options entirely.
4. Always add an "Answer:" line.
   - For Multiple Choice, just the option letter, e.g. "Answer: B"
   - For Fill in the Blank, the accepted answer text, e.g. "Answer: Au"
5. Always add an "Explanation:" line.
6. Optionally add "Level:", "Type:", and "Year:" lines (Mock Tests only use these):
   - Level: Difficult / Moderate / Easy / Basic / Other
   - Type: PYQ / New / Test Series / Notes / Assignment / Other
   - Year: 2011-2026, or NA if the year isn't known
   If you skip these, they default to Moderate / New / NA and can be changed
   later in the editor.
7. If the Mock Test has Sections (e.g. Quantitative Aptitude, Reasoning),
   add a "Section:" line with the EXACT section name you already created in
   the admin panel - e.g. "Section: Quantitative Aptitude". If it doesn't
   match an existing section, the question lands as "Unassigned" and you
   can pick the right section for it after importing.
8. Leave one blank line between questions.
9. Save this file as .docx (Word) or .txt and upload it using "Import from
   Word/Text" in the admin panel. Review the imported questions before saving.
